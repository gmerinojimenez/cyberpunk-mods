Receding Buzzcut
Version: 1.0.0

Adds a NEW hairstyle for male V to the character creator: "Receding Buzzcut".
A short buzzcut with a soft, rounded receding hairline at the temples, with the top
slightly thinner than the sides. Supports every hair color and the facial cyberware
variant.

Nothing in the base game is replaced: the original buzzcut is still available and
NPCs are unaffected.

REQUIREMENTS
- ArchiveXL (and its requirement RED4ext)

INSTALLATION
- Vortex / Mod Organizer 2: install the ZIP directly.
- Manual: copy the "archive" folder into your game folder, e.g.
  C:\Program Files (x86)\Steam\steamapps\common\Cyberpunk 2077\
  These two files must end up in archive\pc\mod\:
    receding_buzzcut.archive
    receding_buzzcut.archive.xl

USAGE
- Open the character creator (male V) and look for "Receding Buzzcut" in the
  hairstyle list. Hair color is changed with the regular hair color option.

UNINSTALL
- Switch to another hairstyle in your save first.
- Delete both files from archive\pc\mod\.

COMPATIBILITY
- Tested on game version 2.5 with ArchiveXL 1.28.2.
- Does not replace any game file, so it should not conflict with other hair mods.
